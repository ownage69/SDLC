# BookShelf — лабораторная работа № 3

Материалы по требованиям к системе управления личной библиотекой.

## Состав

- srs.md — спецификация требований версии 0.2 (черновик);
- img/ — пять мокапов интерфейса и четыре диаграммы;
- sysml/ — текстовая модель требований, предметной области и диаграмм;
- bookshelf-mockups.zip — отдельный архив пяти экранов BookShelf;
- report.docx — отчёт по лабораторной работе.

## Проект

BookShelf — настольное приложение для Windows, рассчитанное на личный каталог книг. Функции первой версии включают ведение каталога, поиск, фильтрацию, сортировку и отслеживание прогресса чтения. Требования и критерии проверки приведены в srs.md.

## Графические материалы

Мокапы показывают каталог, поиск, карточку книги, добавление книги и дневник чтения. Они являются прототипами и не означают, что приложение уже реализовано.

Исходники модели и графов находятся в sysml/ и sysml/dots/. Изображения, используемые спецификацией, находятся в img/.
