# SuperheroLevelCalculator

**SuperheroLevelCalculator** — учебное приложение для оценки физической формы и общего состояния пользователя на основе физиологических и поведенческих показателей.

Проект разработан в рамках дисциплины **«Жизненный цикл разработки программного обеспечения»** и демонстрирует применение архитектурного паттерна **MVC (Model–View–Controller) с активной моделью**.

## Назначение проекта


На основании введенных данных программа:

1. Проверяет корректность входных значений.
2. Вычисляет индекс массы тела (ИМТ / BMI).
3. Рассчитывает итоговое количество баллов.
4. Определяет уровень пользователя.
5. Отображает результат в графическом интерфейсе.
6. При изменении состояния модели автоматически уведомляет представление.

Главная задача проекта — не только реализовать вычисления, но и продемонстрировать **разделение ответственности между Model, View и Controller**.

# 📊 Входные данные

Пользователь вводит следующие параметры:

| Параметр         | Единица измерения | Допустимый диапазон |
| ---------------- | ----------------: | ------------------: |
| **Рост**         |                см |             100–250 |
| **Вес**          |                кг |              30–300 |
| **Возраст**      |               лет |              10–100 |
| **Подтягивания** |               раз |               0–100 |
| **Сон**          |       часов/сутки |                0–24 |

Все значения проходят проверку перед передачей в модель.

# 🚀 Сборка и запуск

После клонирования репозитория перейдите в каталог проекта:

```bash
cd SDLC
```

## Сборка

Выполните:

```bash
dotnet build
```

При успешной сборке проект должен завершиться без ошибок.

## Запуск

Для запуска приложения:

```bash
dotnet run
```
